# Starter catalogue provenance

This 31-resource file is a **manually assembled demo catalogue**, not a MOOCCube/MOOCCubeX, Kaggle, or ITM-Rec download. Titles, providers, resource links and skill tags are curated examples referencing free learning resources. Estimated completion hours and popularity proxies are illustrative values, **not official measurements**. Use the import script for a real, licensed public dataset before making performance claims.

Dataset ingestion: from the backend directory run `python scripts/import_catalog.py input.csv data/imported.json`, then set `SKILLPATH_CATALOG=data/imported.json` and restart the API. Preserve the original dataset's attribution, license, and metadata in this file when replacing the demo.
